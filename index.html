📡 3 — Mesurer le ROS

C'est ici que tu utilises ton ROS-mètre. Choisis plusieurs fréquences autour de ta fréquence souhaitée, puis relève le ROS affiché par ton appareil. Par exemple pour 27 MHz :

26.800 MHz → ROS 2.10
26.900 MHz → ROS 1.65
27.000 MHz → ROS 1.30
27.100 MHz → ROS 1.15
27.200 MHz → ROS 1.20
27.300 MHz → ROS 1.45

Plus tu prends de mesures rapprochées autour du minimum, plus l'analyse sera intéressante.

⚠️ Attention : Le programme utilise le minimum de ROS mesuré comme indicateur de réglage. Avec un simple ROS-mètre, il ne connaît pas directement R et X. Il ne peut donc pas déterminer l'impédance complexe réelle ni affirmer avec certitude que le minimum de ROS correspond exactement à la résonance électrique. Pour le réglage pratique d'une antenne, le minimum de ROS reste néanmoins une information très utile.

🧠 4 — Comment régler l'antenne

Si le minimum de ROS est trop bas

Exemple :

Fréquence souhaitée : 27,000 MHz
Minimum ROS : 26,700 MHz

👉 Pour déplacer généralement le minimum vers une fréquence plus haute : raccourcir légèrement l'élément rayonnant.

Si le minimum de ROS est trop haut

Exemple :

Fréquence souhaitée : 27,000 MHz
Minimum ROS : 27,300 MHz

👉 Pour déplacer généralement le minimum vers une fréquence plus basse : rallonger légèrement l'élément rayonnant.

🔧 Méthode de réglage :
  1. Mesure le ROS sur plusieurs fréquences.
  2. Repère le minimum.
  3. Compare-le avec la fréquence souhaitée.
  4. Modifie très légèrement la longueur.
  5. Refais les mesures.
  6. Répète jusqu'à obtenir le résultat recherché.
Ne coupe jamais une grande longueur d'un seul coup : raccourcis progressivement.

⚠️ Limites du programme

Ce programme est un outil de pré-dimensionnement et de réglage pratique. Il ne mesure pas :
  • R ;
  • X ;
  • l'impédance complexe ;
  • la phase ;
  • le diagramme de rayonnement ;
  • le rendement ;
  • les pertes.
Pour cela, il faudrait un VNA ou un autre appareil capable de mesurer ces paramètres. Mais pour régler une antenne avec un simple ROS-mètre, la méthode Fréquence + ROS est parfaitement exploitable.
