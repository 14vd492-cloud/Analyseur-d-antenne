📡 3 — Analyse VNA

Comment utiliser cette partie : Tu peux entrer les mesures de ton VNA sous forme de tableau. Pour chaque fréquence, entre : ROS si ton VNA donne le ROS, et/ou R + X si ton VNA donne l'impédance. Le programme recherche le minimum de ROS, calcule l'impédance complexe lorsque R/X sont disponibles et estime la bande passante autour du ROS 2:1.

🧠 Interprétation VNA

Important : La fréquence où le ROS est minimum n'est pas nécessairement la fréquence où X = 0 Ω. Pour une antenne, il est donc utile de regarder à la fois :
  • le ROS ;
  • R ;
  • X ;
  • la fréquence de résonance ;
  • la bande passante.

⚠️ Limites physiques

Cet outil est un outil de calcul et d'analyse. Il ne remplace pas une mesure RF réelle. Les résultats réels dépendent notamment :
  • de la hauteur de l'antenne ;
  • du sol ;
  • du diamètre du conducteur ;
  • de la forme de l'antenne ;
  • des objets métalliques proches ;
  • du coaxial ;
  • du système de retour RF ;
  • du transformateur ;
  • des pertes ;
  • de l'environnement.
Le VNA reste la référence pour connaître le comportement réel de l'installation.
